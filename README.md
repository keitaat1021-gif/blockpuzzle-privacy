# BlockPuzzle Privacy Policy

Bilingual (English / Japanese) privacy policy for the BlockPuzzle mobile game.

Hosted via GitHub Pages: **https://keitaat1021-gif.github.io/blockpuzzle-privacy/**

## Updating

1. Edit `index.html`.
2. Bump the "Last Updated" date in the header.
3. Commit and push to `main`.
4. GitHub Pages redeploys automatically.

## Stack

- Single-file static HTML, no build step.
- Vanilla JS language switcher with `?#en` / `#ja` hash routing.
